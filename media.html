Guildhall Application and Animation

The Animation Was Made for a Unit in my IT Course called Animation Creation.

features things such as the stalls on the upper and lower floor, the entrances and more.

the Facebook pages of the Vendors.

The Application Was Made for a Unit in my IT Course called App Development.
It Was Made For The Guildhall and Features info on thing such as
Vendors, Location, Contact Info, Parking, Bookings and features an
account creation and login page where users can create a profile with custom
names and profile pictures.
